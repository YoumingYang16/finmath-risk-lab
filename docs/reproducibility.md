# 复现与结果解释

本文件记录 V1 基线协议。V2 入口为 `scripts/reproduce_v2.py`，V2 方法见 `v2_historical_method.md`、`v2_selection_method.md` 与 `v2_convex_method.md`，以冻结的 `v2_protocol.json` 为准。

## 两类实验的边界

模拟研究固定七种场景、三种手续费、六种候选策略、每场景 1024 条验证路径和 8192 条测试路径。验证和测试使用不同种子。每种场景内所有策略与手续费共享底层路径，以形成配对比较；不能把 126 个测试条件当作彼此独立的市场样本。

协议见 `simulation_protocol.json`，其规范 JSON 的 SHA-256 存入正式结果。协议在当次运行计算结果之前写入。这是代码层面的协议固定和可追踪记录，不是第三方预注册。

历史实验的训练期、验证期、测试期及超参数候选见 `historical_method.md`。测试结果首次看到后，不以测试收益反向选择模型。未来开发如改变模型，应标注新版本，并将既有测试集视作已经查看过的数据。

## 随机性与统计

Monte Carlo 定价在风险中性模型下生成终端状态；对冲研究在规定的物理过程下生成路径。主实验数值上令物理漂移与利率相等是一个设定，不表示两类概率测度概念相同。反变量法以一对路径的平均折现收益为独立单位计算标准误。

模拟的一个主要比较是 S1、5 bps 下验证集所选策略相对 every5 的平均平方终端损失差。负值表示所选策略较低。其 95% t 区间基于独立配对路径；其余比较是探索性、逐项区间，没有家族错误率保证。

历史移动块 bootstrap 保留块内短期依赖，但不能消除非平稳性、制度变化或代理变量偏差。5、21、63 观测的块长用于敏感性分析，不从测试结果中挑选最有利区间。两个汇率系列共享欧元基准和宏观环境，不当作独立的两次试验。

## 风险与成本单位

所有对冲损益均针对一份名义数量为 1 的看涨期权、起始标的价格归一为 100。成本以交易名义金额乘 bps/10000 计收。初始建仓、调仓与终止平仓均计费；费用以融资利率累积至终点后汇总。卖方终端 P&L 已包括共同初始权利金、现金利息、持仓平仓、费用与到期赔付。

损失为负 P&L；RMSE 是相对零 P&L 的平方均值根，不是去均值标准差。VaR95 使用线性经验分位数。ES95 按经验分布最差 5% 的质量积分计算，对尾部边界使用部分权重。负的 VaR 或 ES 可能发生，不截成零。

平均成本预算为初始价格 100 对应的 0.50，仅约束验证样本平均值。测试预算和逐路径预算没有保证；结果单独报告测试是否满足预算。无可行候选时按照预定规则选最低平均成本，标记回退，不隐瞒违反预算。

## 可执行检查

在仓库根目录运行 `python -m pytest`、`python scripts/verify_artifacts.py`。后一命令验证协议哈希、完整条件覆盖、选择是否只依赖验证集、输出有限性、历史结果存在及数据快照哈希等证据，不将文件存在等同于研究结论有效。

性能数字包含设备、库和进程启动开销。并行基准在同样的分块随机数下与串行比较，不用不同任务量制造加速。CI 工作流是供后续远程运行的配置；未在远程执行时不能写作 GitHub Actions 已通过。
