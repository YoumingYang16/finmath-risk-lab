# 数据与研究治理

本研究只使用欧洲央行公开非个人参考汇率。数据快照保留来源 URL、获取记录、原始内容哈希、处理后哈希、日期范围与转换说明。删除其他币种、固定截止日期、排序以及价格归一化均是研究加工，不能把加工数据描述成欧洲央行直接发布的研究结果。原始和处理数据的实际记录以 `data/` 中元数据为准。

数据中的非营业日不补成零收益日。研究用观测步长以及每年 252 个观测的约定近似时间，历史期权期限为 21 个观测，不等同于严格的自然日计息。参考汇率不是买卖报价，价差、市场冲击、信用、保证金、外汇双利率与监管条件未进入模型。

训练、验证、测试按时间分开；标准化、回归系数和偏差校正只在训练数据拟合。允许测试时按已发生的收益更新确定性的滚动/EWMA状态，不允许查看下一步收益后生成当前预测。数据与实验输出保留空值处理和有效样本数。

不收集个人身份、账户、交易记录或健康信息。不存在可以据以实证检验群体公平性的个人样本，因此只讨论数据责任和模型局限，不声称完成公平性评估。将来接入个人数据需另行设计访问、同意、删除及审计机制。

报告区分事实、计算结果和解释。未证明普遍优越性、因果关系、临床可用性或实际盈利。主比较之外的多项结果保留探索性标签。任何后续模型改动应提高协议版本并记录是否已查看既有测试集。
