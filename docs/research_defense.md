# 研究理解与答辩指南

这些问题用于实际学习与复核，不是可背诵后冒充经历的答案。

1. **为什么不是一个股价预测网站？** 研究问题是有限信息与成本如何影响定价和复制误差。每个模块都连接到同一现金流与可检验风险指标。
2. **为什么使用共同权利金？** 若根据每个策略的波动率各收不同权利金，终端误差会同时包含不同初始融资，难以比较对冲规则。本研究统一融资基准，但不声称该基准在跳跃场景是公平市价。
3. **为什么预测准确不必然使对冲更好？** 一步方差代理损失和期权终端现金流损失不同；期限转换、模型错误、调仓与成本会改变排序。
4. **风险中性概率与实际收益概率有何区别？** 前者在定价假设中令贴现资产为鞅，后者描述指定数据生成过程。数值参数恰好相同不意味着概念相同。
5. **为什么反变量 MC 的标准误不能直接按两倍路径数计算？** 一对路径相关，独立单位是每对的平均收益。需以这些均值的方差除以对数。
6. **二叉树为何不能简单把风险中性概率截断到 0 和 1？** 概率越界说明当前网格不满足无套利条件，截断会暗中改变模型；实现拒绝该输入。
7. **对冲顺序如何避免先知？** 用当前观测和当前剩余期限算目标 delta，再持仓经历下一个回报；下一期收益不可进入当前预测。
8. **现金账本如何核验？** 利息、买卖标的、手续费、最终赔付逐行相加。对于相同交易规则，收费 P&L 与免费 P&L 的差必须等于费用终值。
9. **为什么验证集和测试集要分开？** 规则由验证结果选择，测试用来评估这个选择流程；在测试上再次挑选会产生选择偏差。
10. **为何用时间切分而不是随机切分？** 真实决策不能训练于未来。高度相关的邻近日记录被随机拆散还会高估泛化。
11. **QLIKE 中观测平方收益等于潜在方差吗？** 不等于，它是噪声代理；损失的解释需额外条件。某个代理上的改善不等于捕捉真实经济机制。
12. **Ridge 如何体现机器学习而非硬编码？** 标准化参数、系数和校正量从训练样本估计，超参数由验证损失选择，测试不参与拟合。
13. **为什么移动块重采样？** 为保留局部序列依赖。块长敏感性与非平稳性仍限制区间解释，不能将其当作分布无关保证。
14. **ES 与 VaR 的差异？** VaR 是阈值，ES 平均最差一定比例的损失；报告明确有限样本边界质量如何分配。
15. **平均成本约束会保证每条路径都不超预算吗？** 不会，甚至测试平均成本也可能超预算。两种失败必须报告。
16. **为什么多线程或多进程可能更慢？** 小任务的进程启动、序列化和内存开销可大于并行计算收益。基准按等量任务如实记录。
17. **能否用于真实外汇期权？** 当前缺少双利率、真实期权报价、隐含波动率曲面、保证金和执行模型，不能直接作实盘估值或交易服务。
18. **哪些能力仍不能由这个项目证明？** 健康领域兴趣、公共卫生价值判断、团队合作、正式先修成绩，以及本人独立贡献与理解。能力并集应保留这些空缺。
19. **最值得扩展的研究问题是什么？** 以新的独立时间窗比较期限匹配的波动预测；加入真实期权报价后分解定价与对冲误差；研究预算的尾部约束。应先明确识别条件和新数据，再增加复杂模型。
20. **如何诚实呈现给文书老师？** 描述真实问题、方法、负结果、已完成的本人学习/修改和 AI 协助边界；不写发表、导师指导、市场最优或未发生的团队经历。
