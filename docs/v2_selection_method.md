# V2 重复模拟与模型选择研究

本节记录实际执行的模拟协议；主协议为 `docs/v2_protocol.json`，精确执行映射、随机流定义和实施参数在 `results/v2_selection_execution_protocol.json`。两者都在生成本次正式结果之前写入。协议是源文件冻结，不是外部预注册。V1结果没有被覆盖。

## 信息与市场场景

每个场景有24次独立完整流程重复。每次使用独立的60个观察期校准收益，年化样本标准差（ddof=1）乘0.75、1或1.25，形成三个冻结的波动率输入。校准样本与验证、测试和参考评估的随机流互相独立。候选策略看不到模拟器的潜在方差。

| 场景 | 校准与验证分布 | 测试及独立参考分布 |
| --- | --- | --- |
| matched_gbm | GBM，波动率0.20，漂移0 | 同一GBM |
| heston | Heston：v0=theta=0.04，kappa=2，xi=0.30，rho=-0.70 | 同一Heston |
| heston_shift | 上述matched Heston | Heston：v0=theta=0.09，kappa=1，xi=0.45，rho=-0.70 |
| jump_shift | 上述matched Heston | 波动率0.20的补偿Merton跳跃过程：年强度3，log-jump均值-0.06，标准差0.10 |

shift描述的是验证分布与部署评估分布不同，不能写成整个训练／测试都来自同一压力市场。各场景用不同随机流，场景间差不能当作共享路径的配对差。

每次最大验证池256条路径，16／64／256档取其前缀；这些样本量是嵌套设计，不是独立实验。每次测试2,048条，独立参考16,384条。每条路径21次价格变化、期限21/252年，S0=K=100、r=0；所有候选收到相同BS(波动率0.20)初始权利金。这个权利金并非Heston或跳跃情景的市场公平定价，压力场景净P&L因此可能有显著均值偏离；结果同时分解MSE、方差及均值平方。

## 相同候选集上的三种选择目标

三个波动率输入乘四个执行策略，共12个候选。策略为每日delta、每五个观察期delta、半宽0.05和0.10的无交易区间。无交易区间越界后交易到最近边界；共同采取目标delta初始建仓、到期强制平仓。每笔建仓、调整、平仓均计入比例费用。

费用为5／20bps，平均验证费用预算对应0.18／0.72（S0=100的货币单位）。三种选择规则共享校准估计、路径、初始资金、预算和候选集合：

1. forecast_first：按验证QLIKE选择波动率，再在该波动率下选择预算可行、验证净MSE最低的执行策略。
2. joint_mse：直接在全部12个候选中选择预算可行、验证净MSE最低的一对。
3. joint_es90：直接在全部12个候选中选择预算可行、验证损失ES90最低的一对。

无可行候选时按费用、MSE、名称顺序选择，并保留不可行状态。forecast_first的这种回退限于它选中的预测输入，不悄悄换到其他模型。预算是平均样本成本约束，不是每路径现金硬上限。它在测试集和独立参考集上的满足情况分别报告。

QLIKE = log(h) + mean(y)/h，其中 h = 年化波动率平方/252，y为各观察期平方log-return。它是噪声较大的二阶矩代理分数，不是不可观测真实条件方差，也不是期权隐含风险中性波动率。ES90采用上10%经验损失质量，边界非整数时按比例加权；验证16条路径时尾部只相当于1.6条观察，估计不稳定不能被掩盖。

## 账本与统计推断

本实验r=0且策略动作不依赖费用，故同一策略在5／20bps的仓位完全相同。实现先运行零费用账本，再按“净P&L = 零费用P&L - 换手金额×fee/10000”精确计算，已通过所有四类策略与直接含费账本的一致性测试。这一优化不适用于动作依赖费用、余额或保证金的其他策略。

主比较仅有一项：matched Heston、验证64条、5bps，joint_mse减forecast_first的测试MSE差。每次完整重复先产生一个差值，再以24次独立重复构造双侧95%Student-t区间。不能把共享候选、不同费用、嵌套验证档或单次测试路径当作额外完整训练重复。其他配对区间均为探索性点对点区间，没有多重比较的同时覆盖声明。

独立参考集评估相同12个已校准候选，在参考费用预算可行者中选最低参考MSE。差值使用被选策略及参考最优在同一参考路径上的MSE，避免混合两套Monte Carlo样本。参考最优仍是有限带噪声样本的事后有限类参照，不是可部署oracle或全局最优。如果已选策略违反参考预算，其有符号差值不能解释为预算可行集合内的非负遗憾。

## Heston离散化与证据范围

方差采用full-truncation Euler：内部原始方差可负，漂移与扩散系数使用其正部；原始状态本身不硬重置为零。价格采用log-Euler，使用同一时间步开始时的正部方差与相关高斯创新。正式主试验每个观察期4个子步。相关方法来源见 `docs/v2_literature.json` 的L11。

另以两个Heston场景各32,768条路径，分别测试1／2／4／8／16子步，并报告终端价格和方差均值、标准误、call payoff均值与band05对冲MSE。各分辨率使用独立随机样本，既受Monte Carlo噪声也受离散误差影响；这不是共享布朗路径的强误差实验，也不证明单调收敛或精确Heston模拟。

## 实际执行结论

本次共生成11,520个候选评估行和1,728个选择评估行；这些行不是独立市场样本。主比较MSE差为+0.00200259，95%区间[-0.00280276, 0.00680794]，24次完整重复。joint_mse平均MSE为0.27723751，forecast_first为0.27523492。该主实验没有支持joint_mse改善风险的证据，也不能据此证明二者等价。

同条件joint_es90的ES90点估为1.064923，forecast_first为1.087565，但前者MSE为0.301317，高于0.275235。这展示目标之间的取舍；是否显著须查对应探索性配对区间，不能只看均值选出“胜者”。

模拟结果仅针对指定生成机制、期限、候选集合和预算。真实历史结果见独立walk-forward模块；这里不声称实际交易收益、市场最优策略、原创新算法或保证发表。
